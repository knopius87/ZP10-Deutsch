# ZP10 Deutsch – Lernapp NRW

Eine interaktive Lernapp für Schüler*innen der Klasse 10 am Gymnasium NRW zur Vorbereitung auf die Zentrale Prüfung (ZP10) im Fach Deutsch.

## Was kann die App?

Die App bietet schrittweise Algorithmen für alle relevanten ZP10-Aufgabentypen. Für jeden Schritt gibt es eine ausführliche Anleitung, eine Checkliste zum Abhaken und KI-gestütztes Feedback.

**Abgedeckte Aufgabentypen:**
- Aufgabentyp 4a – Prosatext analysieren
- Aufgabentyp 4a – Gedicht analysieren
- Aufgabentyp 2 – Informierenden Text verfassen
- Aufgabentyp 4b – Vergleichen & Bewerten

## Nutzung

Die App läuft direkt im Browser – keine Installation nötig:
https://knopius87.github.io/ZP10-Deutsch

## Hinweise

- Funktioniert auf Handy, Tablet und Computer
- Keine Datenspeicherung
- KI-Feedback wird in Echtzeit generiert
